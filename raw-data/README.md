# Data

This folder contains the raw-data for the different sources in phoible. See the README file in each folder for more information about the source and its contents.

The raw data is provided largely as received from the original source, with some modifications to make it easier to process. The raw data is not meant to be used directly, but rather to be processed by the scripts in the `scripts` folder to produce the aggregated data in the `data` folder. The aggregated data is what is used to produce the phoible.csv file in the `data` folder, which is the main data file for phoible.

If you use the raw data, please cite the original source of the data, as well as phoible.
See the README.md file in each folder for more information about how to cite the original source of the data.
See the [Citing PHOIBLE](../README.md#citing-phoible) section in the root README for more information on how to cite phoible.
